# Multi-Agent Research System

An AI-powered research assistant built with **LangChain, Groq, Tavily, and Streamlit**. The system uses multiple specialized AI agents to automate the research process: searching the web for relevant information, extracting content from web pages, generating a comprehensive research report, and reviewing the report to improve its quality and accuracy. With an interactive Streamlit interface, users can simply enter a research topic and receive a structured, AI-generated report.

**Live Demo:** https://multi-agent-searchsystem.streamlit.app/
